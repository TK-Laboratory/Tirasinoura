# チラシノウラ

好きな文字を好きなだけ打っていいタイピングゲームです。

推奨環境: Windows + Google Chrome

### プレイ方法
→ [ここをクリックしてプレイ](https://tk-laboratory.github.io/Tirasinoura/)
（GitHub Pagesで公開中。）

### 主な機能
- **無制限タイピング**  
  - 好きな文字を好きなだけ打つことができます。
- **リアルタイム統計**  
  - 打鍵数、打鍵速度、入力数、入力速度がリアルタイムで表示されます。
- **グラフ表示**  
  - 打鍵速度、入力速度がリアルタイムでグラフにプロットされます。
  
### 操作
- 文字を入力してスタート
- Ctrl + Enter で終了
- Esc でもう一度
